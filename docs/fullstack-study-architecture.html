프로젝트: Study Platform 대상: 풀스택을 처음 배우는 팀 작성일: 2026-06-25

0. 먼저 이것만 이해하면 됩니다

풀스택은 어려운 말처럼 보이지만, 사실은 사용자가 보는 화면부터 데이터가 저장되는 곳까지 이어지는 전체 흐름을 말합니다. 이 프로젝트에서는 "스터디 모집글을 쓰고, 댓글을 달고, 신청하는 서비스"를 만들면서 그 흐름을 배웁니다.
이 문서는 가장 부담이 적은 A안으로 진행합니다. 하나의 Next.js 프로젝트 안에서 화면, API, DB 연결을 모두 경험합니다. 백엔드를 따로 FastAPI로 분리하는 방식은 나중에 2차 확장으로 미루고, 처음에는 TypeScript 하나로 전체 흐름을 익히는 것이 목표입니다.

프론트엔드

사용자가 직접 보는 화면입니다. 버튼, 입력창, 게시글 목록, 로그인 화면을 만듭니다.

백엔드

사용자의 요청을 받아 처리하는 서버입니다. 글 저장, 로그인 확인, 권한 검사를 담당합니다.

데이터베이스

회원, 게시글, 댓글, 신청 내역이 저장되는 곳입니다. 서비스의 기억장치라고 보면 됩니다.

2. 우리가 사용할 기술 스택

분야 기술 처음 배우는 사람을 위한 설명 이 프로젝트에서 하는 일
언어 TypeScript JavaScript에 타입을 붙여 실수를 줄이는 언어입니다. 프론트와 백엔드 코드를 같은 언어 감각으로 작성합니다.
프론트엔드 React, Next.js React는 화면 조각을 만들고, Next.js는 React 앱을 더 쉽게 서비스로 만듭니다. 목록, 상세, 작성 폼, 로그인 화면, 마이페이지를 만듭니다.
스타일 CSS 또는 Tailwind CSS 화면을 보기 좋게 꾸미는 도구입니다. 반응형 레이아웃, 버튼, 폼, 카드 UI를 만듭니다.
백엔드 Next.js Route Handlers Next.js 프로젝트 안에 만드는 API 서버 코드입니다. 게시글 생성, 댓글 작성, 신청 승인 같은 기능을 처리합니다.
데이터베이스 PostgreSQL 회원, 게시글, 댓글 같은 데이터를 표 형태로 저장합니다. users, studies, comments, applications 테이블을 저장합니다.
ORM Prisma SQL을 직접 많이 쓰지 않아도 DB를 다루게 도와주는 도구입니다. DB 모델을 만들고, 게시글/댓글/신청 데이터를 조회합니다.
인증 Auth.js 로그인 상태를 관리하고 누가 누구인지 확인합니다. 내 글만 수정하기, 신청자 승인하기 같은 권한 처리를 합니다.
배포 Vercel 내 컴퓨터 밖에서도 사이트를 접속할 수 있게 올리는 서비스입니다. 완성한 서비스를 인터넷 주소로 공개합니다.
협업 Git, GitHub 코드 변경 기록을 남기고 팀원과 합치는 도구입니다. issue, branch, pull request, code review를 연습합니다.

3. A안 기준 프로젝트 구조

초보자는 "프론트 파일과 백엔드 파일이 어디에 있는지"부터 헷갈립니다. A안에서는 Next.js 프로젝트 하나 안에 화면, API, DB 코드가 함께 들어갑니다.
1. Next.js 설치 frontend/project-setup에서 앱 생성, TypeScript, ESLint, 폴더 구조를 잡습니다.
2. Prisma 연결 database/schema-design에서 users, studies, comments, applications 모델을 만듭니다.
3. API 작성 backend/board-api에서 app/api/studies 라우트를 만들어 DB와 연결합니다.
4. 화면과 연결 frontend/board-pages에서 API를 호출해 목록, 상세, 작성 화면을 완성합니다.

4. 공부 순서와 브랜치 흐름
